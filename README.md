## ⭐ Featured project

### Clearifix — Business Website

<p>
  <a href="https://www.clearifix.com"><img src="https://img.shields.io/badge/Status-Live_in_production-2ea44f?style=flat-square" alt="Live" /></a>
  <img src="https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white" alt="Next.js" />
  <img src="https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white" alt="TypeScript" />
  <img src="https://img.shields.io/badge/Tailwind_CSS-06B6D4?style=flat-square&logo=tailwindcss&logoColor=white" alt="Tailwind CSS" />
  <img src="https://img.shields.io/badge/Vercel-000000?style=flat-square&logo=vercel&logoColor=white" alt="Vercel" />
</p>

The production website of my own cleaning company — used by real customers, deployed automatically on every push.

- **Contact form** as a server action with input validation, HTML escaping and transactional email
- **GDPR-compliant consent** — analytics and Google Maps only load after opt-in
- **SEO** — metadata per page, sitemap, robots and permanent redirects for removed URLs
- **Refactoring** — reduced the site from 28 pages and a full backend (auth, database, payments)
  to a lean static site: faster, cheaper to run and easier for customers to understand
- **AI-assisted workflow** — planned and reviewed changes with Claude Code, verified every change with a production build before deploying

👉 **[Visit clearifix.com](https://www.clearifix.com)**

**Highlights:**
- User authentication (including guest access)
- Drag-and-drop task management
- Task creation, editing, prioritization, and subtasks
- Dashboard with task overview and deadlines
- Contact management
- Fully responsive interface

**Tech Stack:** HTML, CSS, JavaScript  
**Architecture:** Multi-Page Application (MPA)  
**Repository:** [View Repository](https://github.com/babalushi04/Join)

**My Contribution:**

### El Pollo Loco – 2D Browser Game
A browser-based jump-and-run game developed with **object-oriented JavaScript**.  
This project helped me deepen my understanding of game structure, animations, collision logic, and interactive UI behavior.

**What I worked on / learned:**

- Character movement and animation handling
- Collision detection
- Health/status logic
- Enemy and object interactions
- Sound integration and audio management
- Start screen and game UI improvements
- Background design and visual adjustments
- Organizing game assets and logic in a maintainable structure

**Main Learning Outcome:**  
This project strengthened my understanding of how larger JavaScript projects are structured and how logic, visuals, interaction, and assets work together in a real application.
